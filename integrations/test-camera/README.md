# test-camera 测试摄像头插件

上传一个视频，作为一路**虚拟摄像头**接入 Aether 真实视觉链路，循环播放，用于端到端测试视觉自动化规则。

## 工作原理

```
上传视频(面板) → 宿主落盘 app/data/uploads/test-camera/ → playback.set
  → 插件 cv2 按原FPS采样≤4fps → base64 → 反向RPC camera.push_frame
    → 宿主 VirtualCameraStream → 与真实摄像头完全相同的管线:
    dHash 运动门控 → 视觉规则评估(VL) → 动作执行(默认演练)
```

- 插件启动自动注册一路虚拟摄像头（`vcam_test-camera`，id 恒定），在 `/camera` 预览弹窗与摄像头设置页与真实摄像头**同等地位**。
- **单一当前视频**：上传哪个就循环播放哪个，新上传自动替换；上传目录里的旧视频文件直接删除（目录外的文件绝不碰）。无视频库、无状态文件。
- 帧走**真实链路**——测的就是生产路径本身，不是模拟。
- **默认演练**：规则命中只记录"将执行什么"，不真正调 HA；面板可开"真实执行"开关（只存内存，插件重启回到演练，安全方向）。
- **识别日志**：模型每次识别（预览分类 / 规则判定 / 动作执行或演练）都落 `vision_logs` 表，面板实时展示。

## 使用

1. 插件管理页启用本插件（`/plugin`）。
2. 打开 `/camera` 预览弹窗，切到"测试摄像头"一路，底部出现测试面板。
3. 点「选择视频上传」——上传完成即自动开始循环播放（面板显示当前视频与推帧计数）。
4. 建一条视觉规则绑定该摄像头（camera_id 选"测试摄像头"），条件如"画面中出现人"。
5. 看面板日志：识别 → 规则判定 → 动作（演练）。确认无误后可开真实执行做完整验证。

## 生命周期

- **禁用插件** = 注销虚拟摄像头 + 停止播放；**启用**即恢复（需重新上传/指定视频）。
- **删除插件** = 插件目录 + 上传的全部视频文件 + 该摄像头识别日志 一并物理回收。
