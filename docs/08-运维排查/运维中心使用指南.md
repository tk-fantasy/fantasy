# 运维中心使用指南

> 对应页面：`/operations`（聊天输入 `/operations` 跳转，**仅管理员可见**）
> 权限要求：管理员（首个注册用户）

运维中心把运维能力全部按钮化，无需 SSH 登录主机操作文件。页面分五个模块：

- **系统体检**：一键部署体检（端口/网络/资源/RTSP）
- **诊断包导出**：打包脱敏诊断信息，远程排障用
- **备份与恢复**：创建、恢复、删除备份
- **版本与升级**：查看版本与升级历史；git 一键升级（Gitee，网页内完成）；更新源在线升级（镜像包，交付场景）
- **操作审计**：查看最近运维操作记录

## 2. 诊断包导出

点击「导出诊断包」按钮，自动打包以下内容：

| 内容 | 说明 |
|------|------|
| `config.json` | 脱敏后的配置（密钥字段打码） |
| 系统信息 | uname、docker ps、磁盘/内存使用 |
| 日志文件 | 最近日志（每文件尾部 2MB，总量 10MB） |

**用途**：远程排障时，将诊断包发给技术支持，无需登录主机查看日志。

**安全说明**：
- 密钥字段自动脱敏（显示为 `***...***`）
- 设备 MAC 地址占位处理
- 日志中可能包含设备名、IP 等信息，导出前请确认可分享

## 3. 部署体检

点击「运行体检」按钮，自动检查以下项目：

| 检查项 | 说明 | 通过条件 |
|--------|------|----------|
| 端口占用 | 8010、8123、1884 | 端口未被其他进程占用 |
| HA 连通性 | Home Assistant 地址可达 | HTTP 响应正常 |
| RTSP 连通性 | 摄像头 RTSP 流可达 | cv2.VideoCapture 成功 |
| DNS 解析 | DNS 服务正常 | 可解析域名 |
| 磁盘空间 | 磁盘剩余空间 | > 2GB |
| 内存空间 | 内存剩余空间 | > 2GB |
| NTP 同步 | 时间同步状态 | systemd-timesyncd 正常 |

**体检报告**：每项显示"通过/警告/失败 + 修复建议"，平均 < 10 秒完成。

## 4. 版本与升级

### 4.1 查看版本

显示当前版本号、Docker socket 状态、升级历史。

### 4.2 git 一键升级（Gitee，推荐）

部署来自 Gitee 私库时,在网页上即可完成升级,无需登录主机:

1. **首次启用**(只需一次):主机执行 `docker compose --profile ops up -d --build git-updater` 构建升级执行镜像
2. 获取 Gitee 私人令牌(仓库 → 管理 → 私人令牌,勾选 projects 只读权限)
3. 运维页「git 一键升级」填入令牌保存(存 config.json,诊断包自动脱敏)
4. 点「检查更新」→ 显示当前/远程 commit 与落后数
5. 点「一键升级」→ 自动:拉取代码 → 重建容器 → 健康自检,失败自动回退上一提交,页面自动刷新

升级全程日志在 `logs/git-update.log`(页面上也展示尾部);升级历史照常记入本页(operator=git)。

> 命令行等价物仍是 `./scripts/update-from-git.sh`(SSH 场景或应用起不来时的兜底)。
> 前提:compose 已挂载 docker.sock(默认已挂);工作树必须干净(有未提交改动会中止)。

### 4.3 在线更新源(镜像包通道,交付场景)

适用于有外网环境：

1. 配置更新源地址（`manifest_url`）
2. 点击「检查更新」，显示新版本信息
3. 点击「一键升级」，自动下载 → 校验 → 升级

**更新源配置**：
- 可以是任意静态 HTTP 地址（OSS/COS/GitHub Releases/自建 nginx）
- 格式：`update-channel.json`（包含最新版本号、下载地址、sha256）

## 5. 备份与恢复

### 5.1 创建备份

点击「立即备份」，自动打包：

- `config.json`（应用配置）
- `.env`（API 密钥）
- HA 配置目录（排除运行时产物）
- MQTT 配置
- aether-data 数据卷

**保留策略**：最近 3 份，旧备份自动清理。

### 5.2 恢复备份

1. 选择备份文件
2. 点击「恢复」按钮（需二次确认）
3. 系统停止容器 → 恢复文件 → 重启服务

**注意**：恢复会覆盖当前数据，恢复前建议先导出诊断包备份。

## 6. 审计日志

显示最近 50 条运维操作记录，包括：

- 操作人
- 操作时间
- 操作类型（诊断、升级、备份等）
- 操作详情

**一键清空**：点击「一键清空」按钮（二次确认）可清空全部审计记录。清空动作本身会立即留下一条 `audit_clear` 记录（含操作人与清除条数），保证"谁清空了日志"可追溯。

日志存储位置：`logs/audit/ops_audit.jsonl`（JSONL 格式）

## 7. 数据出网模式

数据出网模式（云端对话/混合/纯内网）在**「高级」页（`/advanced`）的「数据出网模式」卡片**里切换，不在运维中心。聊天页会实时显示当前模式徽标（☁️/🔀/🏠）。三档模式与硬拦截规则详见《[数据流向说明](../tech/数据流向说明.md)》。

## 8. 常见问题

**Q：非管理员能看到运维中心吗？**

A：斜杠命令 `/operations` 对非管理员直接隐藏（菜单里不出现）；直接输网址访问能看到页面骨架，但所有操作返回 403。

**Q：升级失败怎么办？**

A：系统自动回滚到上一版本。如果回滚也失败，请手动恢复备份或联系技术支持。

**Q：诊断包包含敏感信息吗？**

A：密钥字段自动脱敏，但日志中可能包含设备名、IP 等。导出前请确认可分享。

**Q：备份存储在哪里？**

A：存储在宿主机 `backups/` 目录，以 `aether-backup-<时间戳>.tar.gz` 命名。
