# 运维中心使用指南

> 对应页面：`/operations`（聊天输入 `/operations` 跳转）
> 权限要求：管理员（首个注册用户）

运维中心集中管理所有运维功能，无需 SSH 登录主机即可完成诊断、升级、备份等操作。

## 1. 运维中心入口

在聊天页面输入 `/operations` 或 `/ops` 跳转到运维中心。页面分为以下几个模块：

- **诊断与体检**：导出诊断包、运行部署体检
- **版本与升级**：查看版本、上传升级包、在线升级
- **备份与恢复**：创建备份、恢复备份
- **审计日志**：查看运维操作记录

## 2. 诊断包导出

点击「导出诊断包」按钮，自动打包以下内容：

| 内容 | 说明 |
|------|------|
| `config.json` | 脱敏后的配置（密钥字段打码） |
| 系统信息 | uname、docker ps、磁盘/内存使用 |
| 日志文件 | 最近日志（每文件尾部 2MB，总量 10MB） |

**用途**：远程排障时，将诊断包发给技术支持，无需登录主机查看日志。

**安全说明**：
- 密钥字段自动脱敏（显示为 `***...***`）
- 设备 MAC 地址占位处理
- 日志中可能包含设备名、IP 等信息，导出前请确认可分享

## 3. 部署体检

点击「运行体检」按钮，自动检查以下项目：

| 检查项 | 说明 | 通过条件 |
|--------|------|----------|
| 端口占用 | 8010、8123、1884 | 端口未被其他进程占用 |
| HA 连通性 | Home Assistant 地址可达 | HTTP 响应正常 |
| RTSP 连通性 | 摄像头 RTSP 流可达 | cv2.VideoCapture 成功 |
| DNS 解析 | DNS 服务正常 | 可解析域名 |
| 磁盘空间 | 磁盘剩余空间 | > 2GB |
| 内存空间 | 内存剩余空间 | > 2GB |
| NTP 同步 | 时间同步状态 | systemd-timesyncd 正常 |

**体检报告**：每项显示"通过/警告/失败 + 修复建议"，平均 < 10 秒完成。

## 4. 版本与升级

### 4.1 查看版本

显示当前版本号、Docker socket 状态、升级历史。

### 4.2 离线升级

适用于无外网环境：

1. 在有网络的机器上构建升级包（`scripts/build-update-pack.py`）
2. 点击「上传升级包」，选择 `.tar.gz` 文件
3. 系统自动校验 → docker load → 切换版本 → 健康检查
4. 失败自动回滚到上一版本

### 4.3 在线升级

适用于有外网环境：

1. 配置更新源地址（`manifest_url`）
2. 点击「检查更新」，显示新版本信息
3. 点击「一键升级」，自动下载 → 校验 → 升级

**更新源配置**：
- 可以是任意静态 HTTP 地址（OSS/COS/GitHub Releases/自建 nginx）
- 格式：`update-channel.json`（包含最新版本号、下载地址、sha256）

## 5. 备份与恢复

### 5.1 创建备份

点击「立即备份」，自动打包：

- `config.json`（应用配置）
- `.env`（API 密钥）
- HA 配置目录（排除运行时产物）
- MQTT 配置
- aether-data 数据卷

**保留策略**：最近 3 份，旧备份自动清理。

### 5.2 恢复备份

1. 选择备份文件
2. 点击「恢复」按钮（需二次确认）
3. 系统停止容器 → 恢复文件 → 重启服务

**注意**：恢复会覆盖当前数据，恢复前建议先导出诊断包备份。

## 6. 审计日志

显示最近 50 条运维操作记录，包括：

- 操作人
- 操作时间
- 操作类型（诊断、升级、备份等）
- 操作详情

日志存储位置：`logs/audit/ops_audit.jsonl`（JSONL 格式）

## 7. 数据出网模式

在高级设置或运维中心可切换数据出网模式：

| 模式 | 说明 |
|------|------|
| 云端对话 | 对话文本经 HTTPS 到模型厂商（默认） |
| 混合模式 | 对话走云端，敏感角色建议内网 |
| 纯内网 | 所有模型端点必须内网，公网端点硬拦截 |

聊天页面实时显示当前模式徽标（☁️/🔀/🏠）。

## 8. 常见问题

**Q：非管理员能看到运维中心吗？**

A：可以看到页面，但所有操作返回 403 错误。

**Q：升级失败怎么办？**

A：系统自动回滚到上一版本。如果回滚也失败，请手动恢复备份或联系技术支持。

**Q：诊断包包含敏感信息吗？**

A：密钥字段自动脱敏，但日志中可能包含设备名、IP 等。导出前请确认可分享。

**Q：备份存储在哪里？**

A：存储在宿主机 `backups/` 目录，以 `aether-backup-<时间戳>.tar.gz` 命名。
