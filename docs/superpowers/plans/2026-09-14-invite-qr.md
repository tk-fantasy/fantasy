# 邀请码/安装码二维码 + 邀请码24h过期 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 安装码在 8011 页以二维码展示；管理员邀请码在运维页弹二维码深链（扫码直达预填码的注册页）；邀请码签发后 24 小时自动过期。

**Architecture:** 两端各自渲染二维码（结构性：8011 必须在主应用前自包含）：后端 `segno` 服务端出 SVG，前端 npm `qrcode` 出 dataURL。过期改 KV 内邀请条目的数据结构（加 `expires_at` 字段），校验时统一报错维持无侧信道。

**Tech Stack:** Python 3.13 / FastAPI / pytest；Vue 3 / vitest / `qrcode@^1.5.4`；`segno==1.6.6`。

**Spec:** `docs/superpowers/specs/2026-09-14-invite-qr-design.md`

## Global Constraints

- 报错文案不区分码状态（不存在/已用/已吊销/已过期同一句），维持无侧信道

- 8011 是纯标准库 HTTP 服务，任何渲染异常必须降级，绝不阻断/500

- `frontend/dist` 与 `app/static/frontend` 不进 git（构建产物）；同步靠 `npm run build`（内含 `scripts/sync-to-backend.js`）

```js
// 邀请码二维码深链与过期展示的纯函数（便于单测）

export function buildInviteRegisterLink(origin, code) {
  const base = (origin || '').replace(/\/+$/, '')
  return `${base}/login?mode=register&code=${encodeURIComponent(code)}`
}

export function isLoopbackHost(hostname) {
  const h = (hostname || '').toLowerCase()
  return h === 'localhost' || h === '127.0.0.1' || h === '::1' || h === '[::1]'
}

// 存量码无 expires_at → null（视为永不过期）
export function inviteRemainMs(invite) {
  if (!invite || !invite.expires_at) return null
  return invite.expires_at - Date.now()
}

export function formatRemainMs(ms) {
  if (ms == null) return ''
  if (ms <= 0) return '已过期'
  const totalMin = Math.ceil(ms / 60000)
  return totalMin < 60 ? `${totalMin} 分钟` : `${Math.ceil(totalMin / 60)} 小时`
}
```

```js
  }

}
```
