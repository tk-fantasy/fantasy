## 二、安全修复（第 1 批）

| 修复 | 说明 |
|---|---|
| 权限分级 | `POST /api/ha/config`（改全屋 HA 连接）、`POST /api/advanced/config` 收管理员；摄像头全部功能、设备控制、聊天/定时/规则维持全家可用（按产品定位） |
| 注册 | 按用户决策保持开放（原方案审批制被否） |
| exa key 脱敏 | GET 只回 `has_exa_key` 标志；POST 留空=保留旧值（防"打开面板→保存"清空 key） |
| 二级密码防爆破 | 3 个写接口独立限流 10 次/分钟/IP（PBKDF2 29k 轮使在线爆破不可行） |
| SSRF 收敛 | 新增 `net_guard`：模型试连/HA 配置限 http/https、RTSP 试连限 rtsp/http 等流媒体协议（拦 `file://` 等 FFmpeg 任意协议）；摄像头手动指 IP 限局域网 IPv4。刻意**不禁内网地址**——本地 ollama/局域网 HA 是产品核心用法 |
| zip 解压防穿越 | `startswith` → `Path.relative_to()`（堵兄弟目录绕过） |
| env 键名投毒 | 用户保存 key 时 `api_key_env` 限 `LLM_KEY_` 前缀（防覆盖 JWT_SECRET/HA_TOKEN） |
| MQTT | 宿主端口改绑 `127.0.0.1:1884`（HA/simulator 走 docker 内网零影响）；init.sh 弱口令告警 |
| CORS 预检 | api_token_guard 放行 OPTIONS（修跨域预检被 401 拦死）；APP_TOKEN 设置时启动告警 |

## 三、Bug 修复（第 2 批）

1. **聊天建定时任务丢 user_id**：message 类到点必失败、reminder 投递到全系统最近活跃会话 → 工具链路补传
2. **RTSP 试连阻塞事件循环**：断网目标可让全站（聊天/调度/设备控制）冻结数十秒 → 移入线程 + 12s 总超时 + FFmpeg 5s socket 超时
3. **WS 断连丢整轮对话**：收尾 emit 无保护 + `store_session` 被跳过 + 异常静默吞 → emit 断连即静音、落库走 finally
4. **摘要服务形同虚设**：只算不裁、算完不注入 prompt（纯烧 LLM 调用）→ 真裁剪+注入+滚动承接+水位缓存防每轮重跑（`rag.summary_trim_enabled=false` 可回退）
5. **at 任务停机过期假启用**：启动标记 expired 并禁用
6. **会话保存写序竞态**：旧快照覆盖新数据/删除被"复活" → 按 session 链式串行化
7. 裸 `create_task` 补强引用 ×5 处（防 GC 中途回收）
8. **HA WebSocket 错误帧当成功缓存 60s**（设备分组整体消失）→ 校验 id 配对+success
9. validator/schedule_parser 的 httpx 客户端用后关闭（修连接池累积）
10. `at` 的 Z 后缀解析/执行差 8 小时 → 统一本地时间；fallback 规则保留摄像头绑定；external_mcp 竞态修复

## 四、稳定性加固（第 3 批）

| 项 | 内容 |
|---|---|
| 存活自愈 | 无认证 `/healthz` + docker healthcheck——补上"事件循环卡死但进程活着、永不重启"这一 7x24 最大风险；aether 加 `mem_limit: 2g` |
| 健康复检 | HA 每 60s（零成本本地 REST）；LLM 探测默认关闭（烧 token，配置可开）。此前健康状态冻结在启动时刻 |
| 停机链 | 逐项 try/except，单组件清理失败不再跳过其余（session 落库/DB 连接等） |
| 会话治理 | 每用户保留最近 50 个（`storage.max_sessions_per_user`，0 关闭），治内存/启动慢性增长 |
| SQLite 自愈 | 损坏 → rename 保留现场 → backups 恢复 → 裸建（消除断电后启动崩溃循环）。过程中修了两个连带 bug：失败连接未关（Windows 句柄泄漏）→ 文件无法移动；aiosqlite 非 daemon 线程卡死进程退出 |
| 依赖钉版本 | openai<3.0、langchain 系<2.0、aiosqlite==0.22.1（"下次 rebuild 才爆"的延迟雷） |
| WS 断连 | doc_chat 停止 LLM 流（省 token+防 8 线程池被僵尸流占满）；chat_ws 刻意让本轮跑完（小爱播报+完整落库），注释说明 |
| 日志 | sync_ha_ip 计划任务日志 >1MB 自动截断 |

## 五、新功能（第 4 批，与插件完全解耦）

- **离线告警**：摄像头离线（连续 2 周期）/HA 断连/定时任务失败/插件熔断 → 30min 冷却+恢复通知；
  通知渠道为 Notifier 反向注册协议（核心零 import 插件，无渠道时降级日志+WS 推送）；开关 `alerts.enabled`
- **场景模式**：捕获当前设备状态/手动创建/一键应用（单条失败不中断）；REST `/api/scenes` +
  聊天工具 `scene_list/scene_apply/scene_create`；设备页场景条
- **家庭周报**：family_events 统一事件流（90 天自动修剪）→ 周日 20 点 LLM 总结（无 LLM 退化纯统计）；
  默认关闭（`weekly_report.enabled`，消耗 token）；前端 `/report` 页 + `/report` 斜杠命令
