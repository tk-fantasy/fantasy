# Aether 数据流向说明

> 版本：v1（2026-08）· 面向集成商 / 客户交付验收 · 配套《09-商业化工程化清单》条目 4
> 本文即销售/验收用的《数据流向说明》材料，可打印或转 PDF 使用。

## 1. 部署形态与网络拓扑

Aether 部署于**家庭/场所局域网内的树莓派（或任意内网主机）**，所有设备控制闭环不出局域网：

```
                    局域网（家庭 Wi-Fi / 有线）                         局域网外
┌──────────┐   ┌─────────────────┐   ┌──────────────┐
│ 智能设备  │◄──┤ Home Assistant  │◄──┤   Aether     │
│ 灯/空调/  │   │  (8123)         │   │  后端+前端   │
│ 窗帘/传感 │   └─────────────────┘   │  (8010)      │
└──────────┘                         └──────┬───────┘
┌──────────┐   ┌─────────────────┐          │ 仅「云端模式」下，
│ IP 摄像头│──►│   Aether 拉流    │          │ 对话文本经 HTTPS
│ (RTSP)   │   │  画面不出网存储  │          ▼ 出网
└──────────┘   └─────────────────┘   ┌──────────────────┐
                                     │ 模型服务商(可选)   │
┌──────────────┐  OpenAI 兼容端点    │ DeepSeek/OpenAI/ │
│ 内网模型机器  │◄─────────────────── │ GLM/本地 vLLM 等 │
│ Mac+Ollama等 │  (纯内网模式)       └──────────────────┘
└──────────────┘
```

## 2. 三档运行模式（egress_policy）

模式在「高级设置 → 数据出网模式」或初始引导第 4 步切换，聊天页状态条实时显示当前模式徽标。

| 模式 | 出网内容 | 适用场景 |
|------|---------|---------|
| ☁️ **云端对话**（默认） | 对话文本（及云端视觉模型启用时的画面帧）经 HTTPS 发往所选模型服务商 | 追求效果，家中无可跑模型的机器 |
| 🔀 **混合模式** | 对话走云端；视觉/语音转写等敏感角色指向内网模型端点 | 平衡效果与隐私 |
| 🏠 **纯内网** | **零出网**。模型端点全部在内网（Mac 上的 Ollama / LM Studio、自建 vLLM 等，以 OpenAI 兼容 API 接入） | 隐私优先 / 无外网环境；断网可用 |

说明：

- 设备控制指令（开灯、调温等）与 Home Assistant 通信**始终不出局域网**，与模式无关。
- 摄像头 RTSP 流仅在 Aether 进程内做推理，**不落盘、不上传**；只有使用云端视觉模型时才把（降采样后的）帧发给所配置的服务商。
- 模式切换是声明级管控：选「纯内网」但仍有角色指向公网端点时，系统在徽标与状态接口给出醒目警告（不阻断），便于验收时核查。

## 3. 出网点清单（逐项核对）

| # | 数据 | 方向 | 触发条件 | 加密 |
|---|------|------|---------|------|
| 1 | 对话文本（用户输入 + 上下文） | 局域网 → 模型服务商 | 云端/混合模式下的对话、摘要、规则评估 | HTTPS |
| 2 | 摄像头画面帧（降采样 JPEG） | 局域网 → 云端视觉模型 | 仅当视觉模型配置为公网端点 | HTTPS |
| 3 | 语音转写音频 | 局域网 → STT 服务商 | 使用云端 STT 且开启语音输入 | HTTPS |
| 4 | 网页搜索查询词 | 局域网 → Exa | 用户对话触发联网搜索 | HTTPS |
| 5 | 天气查询（经纬度/城市） | 局域网 → 和风天气 | 定时天气卡片刷新 | HTTPS |
| 6 | 设备控制 / 状态 / 摄像头流 | 局域网内部 | 始终 | 不出网，N/A |

> 以上 1–5 在「纯内网」模式下均不发生（4、5 功能停用或不可用，属预期行为）。

## 4. 数据存储与保留

| 数据 | 存储位置 | 保留策略 |
|------|---------|---------|
| 聊天记录、会话 | 树莓派本地 SQLite（`app/data/aether.db`） | 跟随设备，用户可在会话页删除 |
| 账号与密码哈希 | 同上（PBKDF2-SHA256，无明文） | 跟随设备 |
| 各类 API Key | 树莓派本地 `.env`（git 忽略，权限受限） | 不出设备 |
| 摄像头画面 | **不存储**（内存中推理后即弃） | 无保留 |
| 服务日志 | 树莓派本地 `logs/` | 滚动清理 |

## 5. 客户确认（交付留痕）

初始引导第 4 步展示本说明摘要，用户勾选确认后：

- 记录确认人、时间、模式、声明文案版本的 **SHA-256 摘要**到本地数据库（`egress_confirm`），作为交付验收依据；
- 模式后续变更可在「高级设置 → 数据出网模式」完成，状态接口会提示「当前模式与已确认声明不一致」直至重新确认。
