# Aether 数据流向说明

> 版本：v2（2026-08）· 面向集成商 / 客户交付验收
> 本文即销售/验收用的《数据流向说明》材料，可打印或转 PDF 使用。
> v2 变更：移除"三档出网模式/声明签署"功能描述——是否出网由各角色配置的模型端点决定（内网端点即不出网），系统不再单独提供模式开关。

## 1. 部署形态与网络拓扑

Aether 部署于**家庭/场所局域网内的树莓派（或任意内网主机）**，所有设备控制闭环不出局域网：

```
                    局域网（家庭 Wi-Fi / 有线）                         局域网外
┌──────────┐   ┌─────────────────┐   ┌──────────────┐
│ 智能设备  │◄──┤ Home Assistant  │◄──┤   Aether     │
│ 灯/空调/  │   │  (8123)         │   │  后端+前端   │
│ 窗帘/传感 │   └─────────────────┘   │  (8010)      │
└──────────┘                         └──────┬───────┘
┌──────────┐   ┌─────────────────┐          │ 仅「云端模式」下，
│ IP 摄像头│──►│   Aether 拉流    │          │ 对话文本经 HTTPS
│ (RTSP)   │   │  画面不出网存储  │          ▼ 出网
└──────────┘   └─────────────────┘   ┌──────────────────┐
                                     │ 模型服务商(可选)   │
┌──────────────┐  OpenAI 兼容端点    │ DeepSeek/OpenAI/ │
│ 内网模型机器  │◄─────────────────── │ GLM/本地 vLLM 等 │
│ Mac+Ollama等 │  (纯内网模式)       └──────────────────┘
└──────────────┘
```

## 2. 是否出网由模型端点决定

系统不设独立的"出网模式"开关：每个角色（对话/视觉/嵌入/摘要/语音转写）在「API Keys」里配置什么端点，数据就去哪里。

| 各角色端点指向 | 出网内容 | 适用场景 |
|------|---------|---------|
| 公网模型服务商（DeepSeek/OpenAI/GLM 等，默认） | 对话文本（及云端视觉模型启用时的画面帧）经 HTTPS 发往所选服务商 | 追求效果，家中无可跑模型的机器 |
| 内网模型端点（Mac 上的 Ollama / LM Studio、自建 vLLM 等，以 OpenAI 兼容 API 接入） | **零出网**，断网可用 | 隐私优先 / 无外网环境 |

说明：

- 设备控制指令（开灯、调温等）与 Home Assistant 通信**始终不出局域网**，与模型配置无关。
- 摄像头 RTSP 流仅在 Aether 进程内做推理，**不落盘、不上传**；只有视觉角色配置为公网端点时才把（降采样后的）帧发给所配置的服务商。
- 全内网部署：把各角色 base_url 指向内网 OpenAI 兼容端点即可。内置 Ollama（`docker compose --profile local-llm up -d ollama`，端点 `http://ollama:11434/v1`）或内网任意机器上的 Ollama / LM Studio / vLLM，参见《本地Ollama模型部署》。

## 3. 出网点清单（逐项核对）

| # | 数据 | 方向 | 触发条件 | 加密 |
|---|------|------|---------|------|
| 1 | 对话文本（用户输入 + 上下文） | 局域网 → 模型服务商 | 对话/摘要/规则评估角色配置为公网端点时 | HTTPS |
| 2 | 摄像头画面帧（降采样 JPEG） | 局域网 → 云端视觉模型 | 仅当视觉模型配置为公网端点 | HTTPS |
| 3 | 语音转写音频 | 局域网 → STT 服务商 | 使用云端 STT 且开启语音输入 | HTTPS |
| 4 | 网页搜索查询词 | 局域网 → Exa | 用户对话触发联网搜索 | HTTPS |
| 5 | 天气查询（经纬度/城市） | 局域网 → 和风天气 | 定时天气卡片刷新 | HTTPS |
| 6 | 设备控制 / 状态 / 摄像头流 | 局域网内部 | 始终 | 不出网，N/A |

> 以上 1–3 在对应角色端点指向内网模型时均不发生（4、5 为固定外网依赖，功能停用或不可用，属预期行为）。

## 4. 数据存储与保留

| 数据 | 存储位置 | 保留策略 |
|------|---------|---------|
| 聊天记录、会话 | 树莓派本地 SQLite（`app/data/aether.db`） | 跟随设备，用户可在会话页删除 |
| 账号与密码哈希 | 同上（PBKDF2-SHA256，无明文） | 跟随设备 |
| 各类 API Key | 树莓派本地 `.env`（git 忽略，权限受限） | 不出设备 |
| 摄像头画面 | **不存储**（内存中推理后即弃） | 无保留 |
| 服务日志 | 树莓派本地 `logs/` | 滚动清理 |
