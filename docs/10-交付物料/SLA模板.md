# 服务级别协议（SLA）模板

> 使用说明：`【】` 为占位符；服务等级分档处按合同选择保留其一、删除其余；本模板不构成法律意见，正式签署前请经法务审核。

**甲方（客户）**：【客户名称】
**乙方（服务提供方）**：【服务商名称】

## 1. 服务内容

乙方为甲方部署于局域网内的 Aether 智能家居系统（"本系统"）提供以下服务：

1. **部署服务**：在甲方指定硬件（【树莓派/其他内网主机】）上完成本系统及依赖组件的安装、配置与联调；
2. **维护服务**：故障响应与修复、版本升级（离线升级包交付）、数据备份支持；
3. **培训支持**：向甲方指定管理员提供不少于【1】次的使用培训。

## 2. 服务等级与响应时限

| 事件等级 | 定义 | 响应时限 | 解决时限 |
|---------|------|---------|---------|
| P1 严重 | 系统整体不可用，或核心功能（设备控制/联动）不可用 | 【2】小时 | 【1 个工作日】 |
| P2 重要 | 单一功能异常（如某路摄像头、某类设备），有临时替代方案 | 【4】小时 | 【3 个工作日】 |
| P3 一般 | 体验类问题、优化建议 | 【1 个工作日】 | 下一版本规划 |

响应时限的计算以甲方通过约定渠道（【微信群/电话/邮件】）报障并乙方确认为准。

## 3. 远程运维权限范围

1. 甲方了解并同意：排障需要时，乙方可通过甲方授权的远程方式（【远程桌面/Tailscale/甲方导出诊断包回传】）访问本系统，权限仅限：
   - 查看系统日志与脱敏诊断包；
   - 重启本系统相关容器；
   - 执行升级脚本（升级前自动备份，可回滚）。
2. 乙方**不**获取、不存储甲方摄像头画面与聊天内容；诊断包中密钥与个人信息已自动脱敏（详见《数据流向说明》）。
3. 每次远程操作均有审计记录（操作人/时间/动作），甲方可随时查验。
4. 甲方有权随时终止远程通道；终止后乙方仅能以甲方主动回传诊断包的方式支持。

## 4. 升级窗口与变更管理

1. 例行升级安排在【工作日 22:00 — 次日 08:00】；
2. 每次升级前系统自动备份（配置/数据库），失败自动回滚至上一版本；
3. 涉及功能变更的升级，乙方提前【3】个工作日提供变更说明。

## 5. 服务排除

以下情形不在维护范围内：

1. 甲方自行修改系统配置/代码导致的问题（乙方提供有偿修复）；
2. 甲方网络环境变更（路由器更换、网段调整、防火墙策略）导致的连通性问题；
3. 第三方服务（模型服务商 API、Home Assistant 版本更新、摄像头固件）变更导致的不兼容；
4. 不可抗力。

- 超出范围的定制开发按【¥______/人天】另行报价。
