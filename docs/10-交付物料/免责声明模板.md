## 1. AI 控制设备的风险认知

1. 本系统的人工智能功能基于大语言模型对自然语言指令的理解执行设备控制。**甲方理解并确认**：
   - AI 对语义的理解存在不确定性，极端情况下可能执行与甲方意图不完全一致的操作（如误开/误关设备、调节幅度与预期不同）；
   - 涉及安全风险的设备（**门锁、燃气阀门、安防撤防、大功率电器**等）接入自动化/AI 控制前，甲方应自行评估风险并自行决定是否授权；
   - 乙方建议甲方对高风险设备在 Home Assistant 层保留独立的人工控制通道与告警。
2. 因 AI 语义理解偏差导致的设备动作及其后果，在乙方已完成正确部署与配置的前提下，乙方不承担责任；但因系统缺陷（代码 Bug、配置错误）导致的误动作，按《SLA》P1/P2 流程处理并由乙方修复。

## 2. 数据采集与保留

1. **摄像头画面**：本系统在设备内存中处理视频流用于视觉推理，**不落盘存储、不上传**（云端视觉模式下的推理帧除外，详见《数据流向说明》）。录像存储（如客户自配 NAS/HA 录像）由甲方自行管理，乙方不接触。
2. **聊天记录**：存储于甲方本地设备（SQLite），保留期限由甲方自行管理，甲方可随时在界面删除。
3. **账号凭证**：各类 API 密钥仅存储于甲方本地设备，乙方不获取。
4. **诊断数据**：远程排障使用的诊断包已自动脱敏（密钥与个人信息打码），详见《数据流向说明》第 5 节。
