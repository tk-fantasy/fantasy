# 模型家族适配插件（model_adapter）

不同家族的本地大模型各有「小脾气」：比如 Qwen3 的混合思考模型，闲聊/设备控制这类场景其实不需要深度思考，注入一个 `/no_think` 软开关就能大幅降低首字延迟。**模型家族适配插件**就是干这个的——按模型家族封装这类差异行为，而且**适配器不写在宿主代码里**，以集成插件形式安装，宿主零家族特判、零改动。

内置示例：`integrations/qwen-adapter/`（Qwen 系 `/no_think` 注入，实测 LM Studio qwen3.8-27b-mlx「你好」首字延迟 22.6s → 5.0s）。

---

## 一、工作原理

1. 每轮聊天/校验请求发出前，dispatcher 按**当前实际使用的 chat 模型名**（per-user 配置优先，回退全局）查适配器注册表；
2. 模型名命中某插件的匹配规则时，由该适配器改写本轮发送给模型的消息（只改发送副本，不回写会话历史）；
3. 无命中或适配器异常时静默走通用路径，不影响主流程。

失败重试轮与 Validator 重试轮只在最后一条消息上补开关（避免 system 里的标记反复叠加）。

---

## 二、内置插件：qwen-adapter

| 项 | 值 |
|----|----|
| 插件目录 | `integrations/qwen-adapter/` |
| 能力类型 | `model_adapter` |
| 匹配规则 | 模型名含 `qwen`（不区分大小写，覆盖 MLX/Ollama 等变体命名） |
| 行为 | system 末尾追加 `/no_think`，user 消息末尾追加 ` /no_think` |

> `/no_think` 是**软开关**：缩短思考而非完全消除。`max_tokens` 预算记得给残余思考留余量。

## 三、接入新模型家族

写一个插件包即可，宿主代码不用动：

```
integrations/<你的插件id>/
├── manifest.json    # capabilities 声明 model_adapter 能力
├── plugin.py        # 插件入口（可为空壳）
└── adapters.py      # 模块级导出 ADAPTERS 列表
```

`manifest.json` 关键段：

```json
"capabilities": [
    { "type": "model_adapter", "id": "your_family", "priority": 0, "config_schema": {} }
]
```

`adapters.py` 模板：

```python
import re
from app.agents.model_family_adapters import ModelFamilyAdapter

class MyFamilyAdapter(ModelFamilyAdapter):
    family = "myfamily"
    _match_re = re.compile(r"myfamily", re.IGNORECASE)

    def no_think(self, system_text: str, user_text: str) -> tuple[str, str]:
        return f"{system_text}\n/no_think", f"{user_text} /no_think"

ADAPTERS = [MyFamilyAdapter()]
```

要点：

- `matches()` 用 `_match_re.search(模型名)` 判断命中，正则自己定；
- 基类各行为方法默认原样返回，只覆写需要的（当前支持 `no_think`：返回注入「关闭思考」开关后的 `(system, user)` 双文本）；
- `adapters.py` 在**宿主进程内**被 import（`ADAPTERS` 里放类或实例均可），不 spawn 子进程——与传统子进程插件不同，进程内能力不占独立进程。

---

## 四、启停与热刷新

- 插件的启用/禁用、上传、删除（「高级 → 集成插件」页或 `/api/integrations` REST）后，适配器注册表**即时热刷新**，无需重启服务；
- 禁用插件后其适配器立即退出注册表，当轮之后恢复通用路径。

---

## 五、与外部 MCP / 子进程插件的区别

| | model_adapter 插件 | 传统子进程插件（MCP/路由/通知） |
|----|----|----|
| 运行位置 | 宿主进程内 import | 独立子进程，stdio RPC |
| 典型能力 | 模型行为改写 | 网页搜索、通知渠道、STT 等 |
| 只声明 model_adapter 能力的插件 | 不拉起子进程 | — |

宿主对模型家族零特判（`qwen` 字面量只存在于插件目录），有测试守护该约束；所以升级/换模型家族时，优先考虑写适配器插件而不是改宿主。
