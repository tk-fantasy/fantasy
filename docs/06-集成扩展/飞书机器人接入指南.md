# 把 Aether 装进飞书——飞书机器人接入指南

不想开网页也能使唤管家：在飞书里私聊机器人，或者在群里 @ 它，就能对话和控制智能家居。Aether 的飞书集成走**WebSocket 长连接**，由 Aether 主动连飞书服务器收消息——**不需要公网 IP、不需要域名、不需要 ngrok**，家里 NAS / 本机部署就能用。

代码位置：`integrations/feishu/`（宿主侧集成，随主服务启动，删掉目录即整体停用，零影响）。

## 飞书开放平台侧：创建应用并发布

到 [飞书开放平台](https://open.feishu.cn/) 创建一个**企业自建应用**，然后按下面 5 步配置。

### 1. 拿凭证

「凭证与基础信息」页复制两个值：

| 凭证 | 长什么样 | 用途 |
|------|---------|------|
| App ID | `cli_` 开头 | 标识应用 |
| App Secret | 一串密文 | 与飞书建立连接、发消息 |

### 2. 添加机器人能力

「添加应用能力」→ 添加「**机器人**」。没有这一步，应用没有聊天入口，用户搜不到也私聊不了。

### 3. 开通权限

「权限管理」里开通以下权限（收消息 + 发消息，全部应用身份）：

| 权限 | 说明 | 是否必需 |
|------|------|---------|
| `im:message.p2p_msg:readonly` | 读取用户发给机器人的单聊消息 | 必需（收私聊） |
| `im:message.group_at_msg.include_bot:readonly` | 获取群里 @当前机器人 的消息 | 必需（收群聊） |
| `im:message:send_as_bot` | 以应用的身份发消息 | 必需（发回复） |
| `im:message` | 获取与发送单聊、群组消息 | 可选（更宽的集合，开了也行） |
| `im:chat` | 获取与更新群组信息 | 可选 |

### 4. 订阅接收消息事件

「事件与回调」→「事件配置」：

- **订阅方式选「长连接」**（官方推荐，正好匹配 Aether 的实现；选了长连接就**不需要**配置加密策略，Verification Token / Encrypt Key 都可以留空）。
- 添加事件 **`接收消息 v2.0`（`im.message.receive_v1`）**。

> ⚠️ 长连接模式下，事件是 Aether 启动长连接后才能收到的——先在 Aether 侧配好凭证（见下一节），再回到这个页面点「验证连接状态」。

### 5. 发布版本

「版本管理与发布」→ 创建版本 → 设置**可用范围**（全体成员或指定人员）→ 提交发布。

> ⚠️ **权限和事件的变更要发布新版本才对可用范围生效**。只开通权限不发布，机器人依然收不到消息。

## Aether 侧：填凭证

两种方式任选，**管理页优先**：

- **插件管理页（推荐）**：Web 管理页 `/plugin` → 找到「飞书机器人」卡片 → 点开配置弹窗，填 App ID 和 App Secret → 保存。插件正在运行时会**自动热重连**，不用重启服务。
- **`.env`**（老部署兼容）：填 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`（`FEISHU_VERIFICATION_TOKEN` / `FEISHU_ENCRYPT_KEY` 长连接模式下留空即可）。改完重启服务。

配置存在 `config.json` 的 `integration.host_configs.feishu`，secret 字段在管理页脱敏回显、留空保存等于保持原值。

凭证没配时服务照常启动，日志提示「飞书凭证未配置，跳过长连接启动」，属非致命降级；配好后重启或保存配置即拉起。

## 聊天行为

| 场景 | 说明 |
|------|------|
| 私聊 | 直接发消息即可 |
| 群聊 | **必须 @机器人** 才会响应，没 @ 不理 |
| 消息类型 | 只处理**文本**，图片 / 语音 / 表情等忽略 |
| 会话记忆 | 每个聊天（按 `chat_id`）独立上下文 |

内置命令：

- `/clear` —— 清空当前会话的对话上下文，重新开始
- `/help` —— 显示可用命令

## 验证与排错

发布版本后，在飞书里搜到机器人，私聊发一句「你好」，正常应收到 Aether 的回复。

不通时按顺序查（日志里搜「飞书」）：

| 现象 | 日志关键字 | 排查 |
|------|-----------|------|
| 长连接没起来 | `飞书凭证未配置` / `飞书长连接启动失败` | App ID / App Secret 填对没；`.env` 还是管理页，两处别填串 |
| 连上了但私聊不回 | 无「飞书收到消息」日志 | 事件 `im.message.receive_v1` 没订阅 / 权限变更后**没发布新版本** |
| 群聊不回 | 无「飞书收到消息」日志 | 没 @机器人；或缺 `group_at_msg` 权限 |
| 有收到日志但没回复 | `飞书发消息失败: code=…` | 缺 `im:message:send_as_bot` 权限（发版了吗）；code 含义见飞书官方错误码表 |
| 回复重复 | （已修复的历史问题） | 旧版本在 ws 线程里等 LLM 导致心跳超时重连重推，现版本 fire-and-forget，升级即可 |

斜杠命令不经过 LLM，`/help` 有回复说明长连接本身是通的。
